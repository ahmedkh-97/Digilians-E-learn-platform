V0.18.7 — Wide Floating Navbar QA

Reported issue

After the V0.18.6 minimal UI pass, the sticky header looked cleaner but the central navigation became too small on wide desktop screens.

Fix

The floating visual language is retained, but the header is scaled back up:

  • topbar width: essentially full content width
  • desktop center navigation: 620px target width
  • minimum desktop navigation width: 540px
  • five navigation buttons distribute equally
  • brand zone: 230px minimum
  • action/profile zone: 220px minimum
  • sticky offset: 10px

Chromium component QA

The actual production topbar markup from index.html was rendered with the production CSS.

1780px viewport:

  • app shell width: 1380px
  • topbar width: 1388px
  • topbar = 100.6% of shell width, without page overflow
  • desktop navigation width: 620px
  • each of the five nav tabs: ~120.4px
  • sticky top after 700px scroll: 10px
  • horizontal page overflow: 0

1024px:

  • existing responsive behavior takes over
  • horizontal page overflow: 0

390px:

  • mobile responsive behavior remains active
  • horizontal page overflow: 0

Result: PASS.
