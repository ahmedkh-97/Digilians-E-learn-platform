# V0.20.22 — Current-Build Platform Health QA

Date: 2026-09-01

## Goal
Make Private Error Monitor describe the health of the build learners are running now, without deleting historical diagnostics.

## Changes
- Platform Health defaults to **Current Version**.
- Added a local **Current Version / All Versions** scope switch; switching does not refetch analytics.
- Error Events, Affected Sessions, Error-Free Sessions and recent error rows use the selected version scope.
- Current-build sessions are calculated only from events that actually ran the current platform version.
- Generic `Failed to fetch` events are classified and rendered as **Network Warning** instead of **Critical TypeError**.
- Historical errors remain available under **All Versions**.
- Added `Current Build: V0.20.22` badge and a clear `Current version is healthy — 0 errors` empty state.
- Warning rows receive warning styling instead of critical/danger styling.
- Platform Health tests are now part of Quick Check.
