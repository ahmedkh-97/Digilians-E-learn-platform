## Ranking policy

Full Ranked Learning sorts shared results by Completion, Validated Mastery, First Pass, Attempts-to-Best, then Active Solve Time. Duplicate source copies are required for completion but collapse into a single validated concept weight. Study Checkpoints require source-evidence review and never accept learner self-grading as competitive correctness.

Existing 265-question Domain Ranked Learning remains unchanged for deterministic exam-style scoring.

## Safety boundaries

No answer choices, hotspot coordinates, drag/drop ordering, or source facts are invented to force an ambiguous source block into objective scoring. Raw source review banks remain provenance artifacts; `full-ranked-index.json` supplies the ranked-learning interpretation layer.
