V0.20.8 Runtime Compatibility Hotfix — QA

Date: 2026-08-31
Base: V0.20.7 Excel Practice Production V1
Scope: Browser/runtime compatibility only. No educational or assessment-content changes.

Root causes fixed

  1. storage.js and app.js called crypto.randomUUID() directly. Browsers/WebViews without that method could fail while creating a learner playerId or exam clientAttemptId.
  2. The Private Error Monitor counted the known benign browser messages ResizeObserver loop completed with undelivered notifications / ResizeObserver loop limit exceeded as application failures.

Fix

  • Added assets/js/runtime-compat.js.
  • createUuid() uses crypto.randomUUID() when available, then crypto.getRandomValues(), then a final RFC-4122-shaped local fallback.
  • Startup/player ID, exam attempt ID, and anonymous analytics IDs use the shared helper.
  • isBenignClientError() filters only the two known ResizeObserver loop-noise messages before error rate-limit/counting.
  • V0.20.8 cache-busts startup modules so browsers do not mix V0.20.7/V0.20.8 code.
