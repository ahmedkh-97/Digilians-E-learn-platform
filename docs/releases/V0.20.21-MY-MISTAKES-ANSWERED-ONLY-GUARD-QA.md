# V0.20.21 — My Mistakes Answered-Only Guard QA

Date: 2026-08-31

## Requirement
My Mistakes must contain only questions the learner actually answered incorrectly. Correct answers and No Answer / Unanswered questions must not create mistake items.

## Root Cause
Official QBank exam submission previously classified every answer that was not equal to the correct answer as wrong. Because `null !== correctAnswer`, unanswered Official QBank exam questions were added to the legacy Official mistake flags. The legacy My Mistakes importer then used `seedMistake()` with a missing saved answer; `seedMistake()` fabricated a fallback wrong option, causing a No Answer item to appear as a mistake.

## Fix
- Added answered-selection classification helpers in `assets/js/mistakes.js`.
- Official QBank exam submission now saves legacy Official mistake flags only for real answered-wrong questions.
- `seedMistake()` no longer fabricates a wrong option when no answer exists.
- Existing legacy unanswered-only Official imports are pruned when My Mistakes opens.
- Genuine Official Study mistakes are preserved when a real saved Study answer exists.
- Genuine Official Exam mistakes are preserved through their exam context.
- Correct answers still update recovery progress for existing My Mistakes items.
- Quick Local Check now runs both answered-only My Mistakes regression files before localhost can start.
