# V0.21.8 — PL-300 Full Source Ingestion QA

## Goal

Expose every actual question block from both uploaded Microsoft PL-300 source PDFs without weakening the existing reviewed ranked bank or fabricating scoring for visual answer-area interactions.

## Source boundary

- `PL-300 Final.pdf`: 501 pages, 369 actual question blocks.
- `PL-300 Final 2.pdf`: 62 pages, 140 actual question blocks.
- Combined actual source coverage: **509 question blocks**.
- Source 02 ends with a `NEW QUESTION 415` marker followed only by promotional product copy; it is excluded because it is not an exam question.
- Corrected strict normalized source audit: **471 strict unique actual stems**, with at least 38 strict duplicate copies across/within the PDFs.

## Released source-review layer

- `source-01-review-bank.json`: 369 entries.
- `source-02-review-bank.json`: 140 entries.
- **323 `scored-text`** entries preserve parsed source options and answer tokens.
- **186 `source-reveal`** entries preserve complex visual/answer-area evidence without inventing ordinary MCQ scoring.
- **552 derived WebP assets** under `assets/source-review/` preserve question and answer evidence for Hotspot, Drag & Drop, Fill-in-the-Blank, and other visual-heavy items.
- Every review entry preserves `sourceId`, question number/occurrence, source pages, source type, question text or source visual, and source-answer evidence.

## Assessment boundary

- The reviewed ranked PL-300 production bank remains **200 questions**.
- Domain Ranked Learning and Overall PL-300 Ranking continue to use the reviewed production bank only.
- `sourceMockStatus` remains `pending-visual-normalization` and `config.sources` remains empty; the new source review uses the separate `sourceReviewSources` contract.
- Full Source Review is intentionally **non-ranked**.
- No complex visual item is silently converted into a normal MCQ, and no source key is silently corrected by this ingestion pass.

## UI

Microsoft PL-300 now exposes a dedicated **Full Source Review** view with:

- separate buttons for both uploaded PDFs;
- All / Text / Visual-Answer Area filters;
- source question/page context;
- source visuals and static source options where reliable;
- explicit `Reveal answer & explanation` evidence;
- Previous / Next and Jump navigation;
- clear non-ranked labeling.

## Verification contract

Release acceptance requires:

1. 369 + 140 = 509 review entries.
2. No Source 02 promotional Q415 entry.
3. 323 text-scoreable + 186 source-reveal = 509.
4. Every referenced source-review asset exists.
5. No duplicate source-review entry IDs.
6. Existing PL-300 production integration tests remain green.
7. Full platform regression, architecture, Voucher integrity, visual audit, and pre-deploy gates pass on the packaged build.
