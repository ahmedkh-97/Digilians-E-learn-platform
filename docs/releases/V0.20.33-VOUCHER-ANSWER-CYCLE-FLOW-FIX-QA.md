# V0.20.33 — Voucher Answer Cycle Flow Fix — QA

Date: 2026-09-03
Baseline: V0.20.32 — Voucher Competitive Learning UX

## Scope

This release is a bounded Voucher runtime/UX correction based on the PL-300 flow recording reviewed against the V0.20.32 code path.

### 1. Ranked single-choice cycle

V0.20.32 required a second `Confirm Answer` click for every Ranked Challenge question. V0.20.33 shortens the single-choice cycle:

1. learner selects one option;
2. the answer is committed immediately;
3. the answer locks;
4. Instant Feedback opens;
5. the ranked solve timer moves to feedback-paused state;
6. learner continues with Next.

`Confirm Answer` remains required only for native multi-select questions. The learner may build the required answer set while the solve timer continues, then confirm the set once all required selections are present.

### 2. Saved-attempt path interception

The supplied V0.20.32 recording showed `Saved Custom Practice found` when the learner selected the Ranked Challenge. The code already contained an exact Voucher-path matcher, but launch did not use it.

V0.20.33 applies the matcher before opening the saved-attempt modal. The modal now intercepts only an exact match on:

- Voucher track;
- Voucher exam;
- mock kind;
- size mode.

An unrelated Custom Practice therefore no longer resumes or blocks a newly selected Ranked Challenge.

## Regression coverage added

`tests/voucher-cycle-flow.test.mjs` covers:

- single-choice does not require explicit confirmation;
- multi-select does require explicit confirmation;
- ranked single-choice auto-confirms and enters feedback-paused state;
- Confirm Answer is hidden for single-choice;
- saved-attempt modal is gated by exact Voucher path matching.

The new cycle-flow regression test is also part of the Quick Local Check targeted suite.

## Browser acceptance still required on Windows

The execution environment blocks localhost in Chromium by organization policy, so visual/manual acceptance cannot be truthfully claimed here. On the user machine, run `TEST-LOCAL.bat` and verify:

1. Start a Ranked Challenge while an unrelated Custom Practice is saved: the Custom Practice modal must not hijack Ranked Challenge.
2. On a single-choice ranked question: one option click must immediately lock, show feedback, pause the solve timer, and show no Confirm Answer button.
3. On a multi-select ranked question: feedback must stay closed until all required selections are made and Confirm Answer is clicked.
4. Resume the same exact Ranked Challenge: the saved-attempt modal must still offer Resume / Start New Attempt / Cancel.
