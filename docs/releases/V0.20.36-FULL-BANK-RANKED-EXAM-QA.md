# V0.20.36 — Full Bank Ranked Exam QA

Date: 2026-09-04

## Scope

- Add a separate Microsoft PL-300 Full Bank Ranked Exam using all 180 reviewed questions.
- Use a fixed 360-minute continuous ranked timer and Exam Mode feedback at submission.
- Keep the existing 60-question / 120-solve-minute Ranked Challenge unchanged.
- Keep Full Bank ranking isolated from Ranked Challenge Personal Best, Readiness, improvement delta, leaderboard, and Voucher Track Overall.
- Preserve Resume with compact Voucher reconstruction metadata and exact question/option order.
- Preserve Custom Practice as non-ranked.

## Ranking contract

- Ranked Challenge activity: `voucher::data-analysis::microsoft-pl-300::real`.
- Full Bank Ranked activity: `voucher::data-analysis::microsoft-pl-300::full-bank`.
- Each leaderboard keeps one best attempt per learner.
- Ranking order remains score first, then percentage, then faster completion time, then earlier submission.
- Voucher Track Overall continues to use only Real Exam Size activity IDs and does not consume Full Bank attempts.
