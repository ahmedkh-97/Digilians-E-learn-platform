# V0.21.9 — PL-300 Full Source Practice QA

## Scope

- Preserve the two uploaded PL-300 PDF source banks as 509 actual question blocks.
- Make all 509 practiceable without fabricating unsupported visual interactions.
- Auto-score all 323 source text questions from preserved option IDs and answer keys.
- Self-grade all 186 Hotspot / Drag & Drop / Fill-in-the-Blank / answer-area-heavy blocks after source answer reveal.
- Keep Source Practice completely outside Domain/Overall Ranking.
- Persist Source Practice inside the existing `digilians.voucher` owner store and preserve it through backup merge.

## Scoring policy

- `scored-text`: learner selects the original source options; single-select and multi-select are compared to the preserved source key.
- `source-reveal`: learner solves against the original question visual, reveals the original answer evidence, then records `I got it right` or `I missed it`.
- No visual question is converted into invented MCQ distractors.
- Source Practice has `rankingImpact = none`.

## Protected release boundary

The 200-question reviewed ranked `master-bank.json` is not expanded by this feature. Domain Ranked Learning, Overall PL-300 Ranking, timers, first-pass scoring and production answer keys remain unchanged.
