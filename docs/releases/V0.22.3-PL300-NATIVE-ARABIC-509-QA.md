Release date: 2026-09-05

## Release scope

V0.22.3 closes the PL-300 full-source learning regression work while preserving source fidelity across both uploaded source PDFs. The release keeps every source occurrence studyable, upgrades source-backed native interactions where deterministic evidence exists, and resolves Arabic feedback for the complete 509-question source journey.

## Native structured coverage

All **78 / 78** structured source occurrences resolve to supported interaction kinds:

- **71** text-fields
- **5** Yes/No
- **1** choice-fields
- **1** ordered-fields

Yes/No controls are only used when the prompt or structured source contract provides Yes/No evidence. Choice and ordered interactions use source-backed explicit choices only. Missing distractors are never invented from expected answers.

The lazy Full Source Practice renderer retains ordered drag/drop interaction using the source-backed choice pool. The ranked startup renderer keeps compact accessible source-backed controls so the protected startup gzip budget remains intact.

## Arabic feedback

- Arabic explanation resolver: **509 / 509**
- Reviewed questions show Arabic-first learning feedback while preserving the original source explanation as reference evidence.
- The fallback explanation reports the source-approved expected values without adding unsupported choices or facts.

## Visual-only source preservation

`pl300-source-01-q164` is intentionally preserved as a visual-only source occurrence:

- blank extracted question text is not replaced with invented wording;
- original question visual evidence is retained;
- answer visual evidence is retained;
- source explanation remains available;
- the item stays source-reveal/non-objective for accuracy.

## Answer integrity and study behavior

- Submitted answers remain locked for the current attempt.
- Retry starts an intentional new attempt instead of allowing a wrong answer to be flipped into a correct first-pass result.
- Instant Feedback remains available for study-oriented ranked learning.
- Exam-style feedback remains separated from instant explanation behavior.
- Navigator/filter state continues to distinguish current, answered, marked, correct and wrong states according to feedback mode.
- My Mistakes continues to receive deterministic wrong-answer history without turning source-reveal checkpoints into fake scored misses.

## Source-fidelity rules

1. Never invent missing distractors or response choices.
2. Ordered and choice interactions use explicit source-backed choices only.
3. Expected answers are not repurposed as synthetic distractor pools.
4. Yes/No is only promoted when source evidence supports a binary contract.
5. Non-deterministic source-reveal items remain completion checkpoints and are excluded from objective accuracy.
6. Missing text with preserved visual evidence remains visual evidence; it is not silently rewritten.
