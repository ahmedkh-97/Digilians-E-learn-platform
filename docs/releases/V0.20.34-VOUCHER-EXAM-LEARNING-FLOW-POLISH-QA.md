# V0.20.34 — Voucher Exam Learning Flow Polish QA

Date: 2026-09-03

## Scope

- Fix Voucher Custom Practice selected-size visibility for 25 / 50 / 100 / Full Reviewed Bank.
- Keep Confirm Answer exclusive to multi-select and clarify incomplete / ready / confirmed states.
- Keep Voucher Instant Feedback navigation available while reading long explanations.
- Bring newly opened Voucher feedback into view without jumping to the end of the explanation.
- Preserve all assessment content, scoring, ranking, timer, My Mistakes, Official QBank, course Question Banks, course Exams, and protected curriculum data.

## Root causes

1. Voucher selected-size CSS referenced `var(--accent)` without defining `--accent` on Voucher surfaces. The background declaration became invalid while the active text changed to white, producing the white/blank-looking selected control.
2. Multi-select Confirm used the primary button visual even while disabled, so its readiness state was ambiguous.
3. Exam actions remained after the full feedback block, forcing learners to scroll through long explanations before reaching Next.
