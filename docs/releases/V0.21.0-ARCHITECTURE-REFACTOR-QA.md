# V0.21.0 Architecture Refactor QA

Date: 2026-09-04

## Scope

Behavior-preserving architecture baseline covering Design Tokens, Storage boundaries, Exam Engine core/facade, Exam Modes, Voucher facade, Ranking scopes, and permanent architecture validation.

## Architecture contracts

- `app.js` routes exam core behavior through `exam-engine.js`.
- `app.js` routes Voucher core behavior through `voucher-engine.js`.
- Ranking Center aggregate scope logic lives in `ranking-scopes.js`.
- Light/Dark semantic variables load from `assets/css/tokens.css` before `style.css`.
- Ranking preferences and Avatar profile persistence pass through the central storage boundary without changing legacy storage keys.
- `tools/architecture-check.mjs` blocks circular JS imports, facade bypasses, orchestrator storage leaks, and unresolved CSS custom properties without fallbacks.

## Protected behavior

No intended change to questions, answer keys, timer rules, Resume schema, My Mistakes, ranking activity IDs, Supabase contracts, Official QBank, course banks, or Voucher assessment payloads.

## Release gate

Automated evidence is generated by `tools/quick-local-check.mjs` and `tools/pre-deploy-check.mjs`. Final release acceptance also requires the manual browser checklist supplied with the release handoff.
