# V0.20.20 — Track-Grouped Exam Navigator QA

Date: 2026-08-31

## Requested UX
The question navigator now groups question numbers by Data Analysis track only. It no longer repeats topic/section blocks inside the navigator.

Examples:
- Excel → every Excel question number in the current exam.
- SQL → every SQL question number.
- Python → every Python question number.
- Power BI / Tableau / Looker Studio → same behavior when present.

Track groups are ordered by the first appearance of each track in the generated exam. Question numbers inside each track remain in original exam sequence order.

## Safety Fix Required by Visual Regrouping
Visual regrouping can change DOM button order, so every navigator button now stores its immutable original question index in `data-nav-index`. Navigator state rendering resolves Current / Answered / Correct / Wrong / Marked against that original index rather than DOM position.

This preserves assessment behavior while allowing non-contiguous questions from one track to render together.

## Preserved Context
- Current-question source bar still shows source / level / track / topic.
- Exam activity context remains unchanged.
- Question order and Next/Previous sequence remain unchanged.
- Navigator group collapse/expand remains available.
