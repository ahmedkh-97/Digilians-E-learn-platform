## Scope

Fix the real Windows acceptance failure in `tools/windows-basic-check.ps1` caused by ambiguous PowerShell variable interpolation before a colon.

Production change:

- `Fail "JSON $Relative: ..."` → `Fail "JSON ${Relative}: ..."`
- Added a permanent regression guard that scans shipped PowerShell fallback scripts for unsafe unbraced `$Variable:` interpolation, excluding valid PowerShell scopes such as `$env:`.
- Updated release/version/cache markers to V0.20.26.
- Corrected README wording so ordinary Windows localhost use is not described as Node-required.

No Voucher question content, Official QBank content, course Question Banks, Exams, scoring, Ranking rules, My Mistakes rules, or learner data schema changed.

## Windows Runtime Note

The current automated verification environment is Linux and does not provide `powershell.exe` or `pwsh`, so the Windows PowerShell script cannot be executed natively here. The exact parser defect reported during real Windows acceptance is covered by the new static regression guard, and final Windows acceptance is performed by running `START-LOCAL.bat` on the learner's Windows machine without Node.js.
