# V0.20.44 — Exam Engine Refactor Phase 2E QA

## Scope

Behavior-preserving Exam Engine integration cleanup. `app.js` now consumes the extracted Session, Timer, Answers, Navigation, Persistence, Feedback and Results cores through `assets/js/exam-engine.js` rather than importing each core module directly.

## New integration boundary

- `assets/js/exam-engine.js` — single application-facing Exam Engine facade.
- `createExamSession(...)` — one entry point for fresh and restored session creation.
- Existing pure core functions are re-exported without changing their contracts.

## Invariants

- No question or answer-key changes.
- No LocalStorage key or Resume schema changes.
- No timer-policy changes.
- No answer-cycle or navigator behavior changes.
- No scoring, feedback timing, ranking scope or My Mistakes behavior changes.

## Automated gates

- Focused `refactor-exam-engine-integration.test.mjs` Red → Green coverage.

- Full Pre-Deploy requires `exam-engine.js` and runs the complete Node regression suite.
- Windows Basic Check requires `exam-engine.js` before localhost startup.
