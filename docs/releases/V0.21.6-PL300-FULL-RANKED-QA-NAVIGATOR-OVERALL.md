# V0.21.6 — PL-300 Full Ranked QA: Navigator Status, Filters & Overall Ranking

Release date: 2026-09-05

## Scope

- Complete the V0.21.5 PL-300 Domain Ranked Learning QA pass.
- Fix grouped Section Navigator answer-state colors seen in Instant Feedback.
- Fix the Answered navigator filter, which previously normalized back to All.
- Preserve Marked as an independent star overlay so a marked question can still show Correct/Wrong status.
- Implement the promised Overall PL-300 Ranking from the four official Domain leaderboards.
- Preserve Voucher breadcrumbs, Domain/Section context, 200-question PL-300 bank, and protected non-Voucher assessments.

## Root causes fixed

1. `voucher-domain-navigation.js` accepted only `all`, `unanswered`, and `marked`; the visible `answered` control therefore normalized to `all`.
2. The grouped Domain renderer collapsed every answered item to `answered-neutral`, so it discarded the Instant Feedback Correct/Wrong state that the flat navigator already supported.
3. Marked state was being treated as the answer status rather than an independent overlay in the grouped navigator.
4. The Domain landing UI promised an Overall rank after all four Domains, but only individual Domain leaderboards were wired.

## Overall PL-300 ranking contract

A learner enters the Overall PL-300 leaderboard only after an official completed attempt exists in every released PL-300 Domain. The board selects the best official attempt in each Domain and aggregates:

1. Total mastery / total correct across all Domains.
2. First-pass correct across all Domains.
3. Sum of attempts-to-best across Domains.
4. Sum of Active Solve Time across the selected Domain bests.

Tie-break order is Total Mastery → First Pass → Attempts-to-Best → Active Solve Time.

## Manual acceptance focus

1. Start Prepare the Data with Instant Feedback. Answer one question correctly and one incorrectly; the Section Navigator must show green/red respectively.
2. Mark either answered question; its Correct/Wrong color must remain and the star must overlay it.
3. Verify `All`, `Unanswered`, `Answered`, and `Marked` filters each show only the intended stable question numbers.
4. Switch to Feedback at End; answered questions must be neutral answered state and must not expose Correct/Wrong before submission.
5. Exit/Resume and verify Domain, current question, answers, marks, feedback mode, filter-independent numbering, and section context restore correctly.
6. Complete a Domain and verify Domain Ranking remains scoped to that Domain.
7. Open `View PL-300 Overall Ranking`; learners missing any Domain must not join the official board.
8. With four official Domain bests, verify overall totals cover all 200 released questions and ranking follows Mastery → First Pass → Attempts → Active Solve Time.
9. Confirm V0.21.5 Voucher breadcrumbs remain Voucher → Microsoft PL-300 → Domain and Domain → Section.
