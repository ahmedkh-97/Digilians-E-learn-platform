# V0.20.31 — Voucher UX Restructure QA

## Scope

This release reorganizes the Voucher user flow based on manual review of the supplied screen recording. It is a UI/navigation release only: assessment content, scoring, Safe Shuffle, Resume, Ranking rules, My Mistakes rules, and protected course/Official payloads remain unchanged.

## UX changes

- Voucher Hub hero is shorter so track choices surface earlier.
- Voucher child navigation (`Hub → Track → Exam`) resets to the top immediately instead of visibly smooth-scrolling through the next view.
- Voucher Track exam cards hydrate reviewed-question counts from the live exam config rather than copied registry text.
- Microsoft PL-300 now presents two primary preparation paths:
  - Practice: 25 / 50 / 100 / Full Reviewed Bank, non-ranked.
  - Real Exam Simulation: 60 questions / 120 minutes / 70% pass, rank eligible under the existing ranking rules.
- Full Source Mocks use a compact pending/released strip instead of a large empty section.
- Empty Attempt History is compact until attempts exist.
- Exam Ranking is colocated with Real Exam; Track Overall Ranking is colocated with the exam hero.
- `Full Bank` is labeled `Full Reviewed Bank` to avoid implying that unreleased draft/source questions are included.
