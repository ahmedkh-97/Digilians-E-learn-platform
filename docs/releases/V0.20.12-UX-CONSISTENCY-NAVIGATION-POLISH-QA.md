# V0.20.12 — UX Consistency & Navigation Polish QA

Date: 2026-08-31

## Scope

Targeted UX polish only. No redesign, learning-content edits, assessment-bank edits, ranking-rule changes, or learner-data migrations.

## Changes

- Full Track Exam setup/back, active-exam exit, result next action, and review home return to the originating learning track.
- Setup back label reflects the selected track for Full Track Exams.
- Global `:focus-visible` indicator added for keyboard navigation.
- Dark Mode `Mark for Review` text uses the theme warning token for readable contrast.
- Exam answered progress and instant feedback are polite live regions.
- Pre-Deploy permanently runs the UX consistency regression test.
- Corrected the historical README heading for V0.20.10 Platform Stabilization & Data Safety.

## Audit Evidence

- The prior Full Track Exam flow returned non-official track exams to `examsView`/`dashboardView`, losing the learner's track context.
- The small Dark Mode Mark text used light-theme brown values. Approximate contrast against the dark surface was below 4.5:1; the dark warning token is substantially higher contrast.
- Interactive controls had inconsistent focus-visible treatment.
