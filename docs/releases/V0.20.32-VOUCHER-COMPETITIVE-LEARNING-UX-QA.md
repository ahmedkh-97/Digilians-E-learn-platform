# V0.20.32 — Voucher Competitive Learning UX — QA Report

## Release scope

V0.20.32 restructures Voucher around a competitive learning loop while preserving existing assessment payloads and ranking boundaries.

Key shipped behaviors:

- Rank-first PL-300 dashboard with Current Rank, Personal Best, Digilians Readiness, improvement and next-rank target.
- Ranked Challenge contract fixed to 60 questions / 120 solve minutes / Instant Feedback / Ranked.
- Ranked answers require confirmation, then lock before feedback appears.
- Ranked solve timer runs only while solving; it pauses during confirmed feedback. Away time while solving still consumes time; away time while confirmed feedback is open does not.
- Voucher direct launch removes the duplicate feedback-mode setup step.
- Saved attempts use an in-app modal instead of browser `confirm()`.
- Improve My Level builds a 25-question non-ranked Instant Feedback session from weak domains, active Voucher mistakes and unseen reviewed questions.
- Voucher Focus Mode hides the main platform navbar while solving.
- Navigator adds All / Unanswered / Answered / Marked filters, answered/marked/remaining summaries and question-card scroll anchoring.
- Multi-select questions show live selection counts before confirmation.
- Learner-facing feedback is cleaned of internal implementation language and structured around correct answer, reasoning, reviewed distractors and Exam Tip when available.
- Ranked results and Attempt History surface readiness, solve-only time and improvement actions.

PL-300 reviewed production content remains 180 canonical questions with 90 drafts fail-closed.
