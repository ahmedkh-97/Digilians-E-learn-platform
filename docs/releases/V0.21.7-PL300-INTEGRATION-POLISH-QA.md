## My Mistakes contract

PL-300 Voucher mistakes can now retain and safely backfill:

`Voucher → Microsoft PL-300 → Domain → Section`

The My Mistakes page exposes Voucher-only cascading Domain and Section filters. Search/cards include the same canonical context. Existing Course and Official QBank mistakes remain compatible.

## Section Analytics contract

Each PL-300 Domain detail renders canonical section order from `content-architecture.json`. The best official completed Domain attempt supplies section correct/wrong totals; the UI derives percentage, state, strongest section, and weakest section. Before an official attempt, canonical sections render as not attempted instead of inventing scores.
