# V0.20.28 — Voucher Ranking Center Integration QA

## Scope
Integrates Voucher Exam Ranking and Voucher Track Overall as first-class modes inside the existing Ranking Center on top of V0.20.27. No ranking eligibility rule, assessment payload, scoring rule, My Mistakes rule, storage schema, or learner-state behavior is intentionally changed.

## Product changes
- Adds `Voucher Track Overall` and `Voucher Exam Ranking` to the main Ranking Center tabs.
- Adds a Voucher-specific track selector and Real Exam selector inside the Ranking Center.
- Both Voucher ranking modes remain visible before any Voucher exam is released and show explicit empty states.
- Released rank-eligible Voucher exams automatically populate the Voucher Exam Ranking selector from the Voucher registry.
- Voucher Track Overall defaults to the learner's Primary Track when available, while other tracks remain viewable.
- Existing standalone Voucher leaderboard routes remain available from individual Voucher exam/track pages.

## Ranking rules preserved
- Voucher Exam Ranking: Real Exam Size only; best attempt per learner; score first, time tie-breaker.
- Voucher Track Overall: best Real Exam Size attempt per released exam; fixed total question denominator; Primary Track members only.
- 25 / 50 / 100 / Full Bank practice attempts remain unranked.
