# V0.21.4 — PL-300 Domain Ranked Learning QA

Release date: 2026-09-05

## Scope

- Replace PL-300 Session Ranking as the primary competition flow with four Domain-ranked activities.
- Keep the ten curriculum sessions as visible Sections inside each Domain attempt.
- Support Ranked Instant Feedback and Ranked Feedback at End with Active Solve Time instead of countdown pressure.
- Add a grouped Section Navigator on desktop and a drawer trigger on mobile.
- Preserve legacy Session, 60Q and Full Bank attempt history without exposing them as the primary PL-300 path.
- Bypass legacy Voucher mock-size validation for structured Domain attempts.
