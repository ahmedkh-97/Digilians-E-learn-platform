# V0.20.16 — Section-Aware Exam Navigator QA

Date: 2026-08-31

## Scope

Bounded exam-navigation UX improvement built from the deployed GitHub Pages artifact for commit `c54b13fc59966346a5f0211fdefaa9af515c889f`.

The release keeps the existing V0.20.15 activity/question context and adds section-aware grouping inside the question Navigator.

## Implemented

- Question numbers are grouped by contiguous `Track · Section/Topic` metadata.
- Question order is never changed to create a group.
- If the same topic appears again later, it starts a new visual group in that later position.
- The group containing the current question is visually highlighted.
- Groups show their question count and can be collapsed/expanded.
- Moving to a question inside a collapsed group automatically expands that group.
- Runtime navigator buttons now expose display Track/Topic metadata so grouping also works for ordinary Course Practice/Exam payloads, not only generated Official QBank/My Mistakes activities.
- Responsive number grids retain the platform's 5-column desktop / 8-column tablet / 6-column mobile behavior.
