# V0.20.46 — Voucher & Ranking Refactor QA

## Scope

Behavior-preserving Phase 4 refactor. Voucher core dependencies now enter the application through one facade, while Ranking Center mode validation and Official QBank aggregate scope computation live in a pure ranking-scope module.

## New boundaries

- `assets/js/voucher-engine.js` — app-facing facade over Voucher registry, bank selection, Voucher storage, ranking, ranked timer runtime, and readiness/improvement modules.
- `assets/js/ranking-scopes.js` — supported Ranking Center mode registry plus pure Junior/Professional/Track fixed-section scope construction.
- `app.js` no longer imports six Voucher core modules directly and no longer owns fixed-section catalog or aggregate ranking scope computation.

## Manual acceptance gate

1. Start with `START-LOCAL.bat`.
2. Open Voucher → Data Analysis → PL-300 and verify Custom Practice and Ranked Challenge open normally.
3. Complete/enter one Ranked Challenge question and verify ranking action still routes to the Voucher Exam leaderboard.
4. Open Ranking → Voucher Exam and verify PL-300 leaderboard scope and attempts display normally.
5. Open Ranking → Voucher Track Overall and verify Data Analysis Track Overall loads with the same scoring rules.
6. Switch Ranking to Junior Overall, Professional Overall, Track, and Individual Exam and verify each scope renders normally.
7. Refresh and confirm the selected Ranking mode/track/exam remains saved.
