# V0.22.2 — PL-300 Study UX & Answer Lock — QA

Date: 2026-09-05

## Scope

V0.22.2 improves the PL-300 509/509 ranked study experience without changing the protected 509 source-occurrence coverage or the 265 validated-concept competitive weighting.

## Implemented behavior

- **Answer Lock:** once Check Answer grades an occurrence, its saved response is authoritative and the answer controls are disabled for that attempt.
- **Retry Question:** an explicit retry opens a fresh attempt; storage continues to preserve `attemptCount`, `firstPassCorrect`, and `everCorrect`.
- **Source-backed dropdowns:** the Native Structured renderer uses `<select>` only when a reviewed field contains explicit source choices. Source 01 Q5 and Q6 are the first verified dropdown conversions; free-text fields remain text inputs rather than receiving invented distractors.
- **Arabic-first explanation:** reviewed/mapped Arabic explanations appear before the optional collapsed Original Source Explanation.
- **Mini Parts:** Full Ranked Learning is organized as Domain → Section → Mini Part, with balanced study batches capped at 20 questions and an All 509 Questions view.
- **Unclassified coverage:** source occurrences lacking complete classification remain visible in explicit Source Review / Unclassified Source Questions parts.
- **Safe cleanup:** root Windows scripts moved to `tools/windows/`; development workflow notes moved to `docs/development/`. Runtime, assessment, source-review, and visual evidence assets are preserved.
