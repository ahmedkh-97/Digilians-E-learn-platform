# V0.21.3 — PL-300 Ranked Learning Core QA

Release date: 2026-09-04

## Scope

This checkpoint rebuilds the primary Microsoft PL-300 Voucher flow around the approved ten revision sessions. The former 60Q Ranked Challenge and Full Bank Ranked Exam are removed from the primary PL-300 Ranked Learning UI and retained only for legacy attempt compatibility. Quick Practice remains secondary and non-ranked.

## Ranked Learning contract

- Every PL-300 session is a ranked activity.
- Learners can choose Instant Feedback or Feedback at End; both feed the same session leaderboard.
- Session ranking uses final mastery, first-pass accuracy, attempts-to-best, then active solve time.
- Active Solve Time excludes instant-feedback reading time and safe exit/away time.
- A session attempt becomes official only when every question in the session is answered.
- Incomplete attempts remain provisional/local and are not submitted to the shared leaderboard.
- Session results expose Retake Session, Session Ranking, and My Mistakes.
- Historical 60Q / Full Bank attempts remain readable as legacy history only.

## Release identity hotfix

V0.21.2 could display V0.21.1 in the HTML runtime identity, which caused the update manager to repeatedly detect an update after reload. V0.21.3 adds a permanent release-identity regression gate that requires VERSION.txt, HTML runtime identity, cache-busting versions, update fallback, and changelog latest version to match.

## Manual acceptance focus

1. PL-300 landing shows Ranked Learning sessions as the primary path and no primary 60Q / Full Bank cards.
2. Start one session with Instant Feedback; feedback appears after answer and the active solve timer pauses while feedback is read.
3. Start one session with Feedback at End; answered questions count as answered in the navigator and no immediate feedback appears.
4. Exit and resume a ranked session; session identity, answers, marks, first-pass state, and timer restore correctly.
5. Finish a full session; result shows mastery, first-pass accuracy, active solve time, official rank eligibility, Retake Session, Session Ranking, and My Mistakes.

7. Submit an incomplete session and verify it is provisional and not shared as an official leaderboard attempt.
