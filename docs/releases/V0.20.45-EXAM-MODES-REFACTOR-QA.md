# V0.20.45 — Exam Modes Refactor QA

## Scope

Behavior-preserving Phase 3 refactor. Exam behavior is now resolved through explicit pure mode profiles instead of scattered combinations of feedback, ranking and Voucher flags.

## New mode boundary

- `assets/js/exam-modes.js` — explicit mode registry and `resolveExamMode(...)`.
- Supported profiles: Course Practice, Course Exam, Official Practice, Official Exam, My Mistakes Practice, Voucher Practice, Voucher Ranked Learning, Voucher Full Bank Ranked and Voucher Improvement.
- `assets/js/exam-engine.js` re-exports the mode contract so `app.js` continues to consume one Exam Engine facade.
- `app.js` stores one active `state.examMode` at exam start and uses it for mode-sensitive analytics and Voucher result labeling.

## Invariants

- No question or answer-key changes.
- No LocalStorage key or Resume schema changes.
- No timer-policy changes.
- No answer-cycle or navigator behavior changes.
- No ranking activity-ID or leaderboard-scope changes.
- Ranked Challenge remains instant-feedback solve-time competition.
- Full Bank Ranked Exam remains feedback-at-end continuous-ranked competition.
- Improvement and Custom Practice remain non-ranked.
- Official QBank ranking remains independent from feedback style.
