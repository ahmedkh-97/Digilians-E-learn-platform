# V0.20.14 — Excel Full Track Exam Flow Fix QA

## Scope

Bounded UX/logic correction for the third card in the Excel Study → Practice → Exam learning flow.

## Fixed

- Excel Week modules no longer show a misleading disabled `Exam Building` card when the ready Full Track Exam exists.
- The third card resolves to `data-analysis-excel-track-v1` for Excel only.
- Card copy is explicit: `FULL TRACK EXAM`, `50 Questions · 60 Minutes · Ranked`, and `Covers all 3 Excel weeks`.
- Status uses the real Full Track state: `Not attempted`, `Best N%`, or `In progress`.
- Saved Full Track attempts use `Resume Full Track Exam`; otherwise the card uses `Start Full Track Exam`.
- Selected-module copy distinguishes week-scoped Study/Practice from the all-weeks Full Track Exam.
- The duplicate standalone Excel track-exam row is removed; the flow card is the single primary CTA.
- Removed stale unused module-flow assessment code that referenced an undefined `assessmentReady` variable.
- Non-Excel module-exam behavior remains unchanged.

## Regression Protection

`tests/excel-module-full-track-card.test.mjs` protects:

1. Excel module → Full Track Exam resolution.
2. Full Track scope/copy.
3. Start vs Resume status behavior.
4. Non-Excel module behavior.
5. Selected-module scope explanation.
6. Duplicate track-exam-row prevention.

The test is included in the Excel Full Track Exam Pre-Deploy gate.
