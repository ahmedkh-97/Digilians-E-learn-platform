# V0.20.23 — Official Final Feedback Mode Choice QA

Date: 2026-09-01

## Change
The ranked Official QBank Final simulation now opens the existing Exam Settings screen with two learner-selectable modes:

- **Instant Feedback** — after an answer is selected, that answer is locked and the correct answer/explanation is shown immediately.
- **Exam Mode** — feedback remains hidden until the full exam is submitted.

The same reusable behavior is enabled for both Junior and Professional Official Final simulations.

## Implementation
- `buildOfficialFinal` now reads `blueprint.feedbackModes` instead of hard-coding Exam Mode.
- Active Junior and Professional Official Final blueprints declare `['instant','exam']`.
- `prepareOfficialFinalExam` opens setup without forcing `exam`, so the learner can choose.
- Existing generic exam persistence continues storing `feedbackMode`, so Resume preserves the mode of the unfinished attempt.
- The 120-minute Final timer remains enabled in both modes.
