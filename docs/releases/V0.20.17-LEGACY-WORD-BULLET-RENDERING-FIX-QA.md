# V0.20.17 — Legacy Word Bullet Rendering Fix QA

Date: 2026-08-31

## Root Cause
Five Looker Studio Official QBank questions contain the legacy Microsoft Word/Wingdings private-use bullet character `U+F0B7` in their source text. The universal display sanitizer removed bidi controls but did not normalize this legacy glyph, so browsers could render it as an unreadable symbol.

## Fix
- Normalize `U+F0B7` to the standard Unicode bullet `•` inside `sanitizeDisplayText`.
- Keep the Official QBank source JSON unchanged.
- Preserve line breaks and code characters for SQL / Python / DAX / Excel / Power Query M.
- Cache-bust the shared `technical-content.js` renderer for V0.20.17.
