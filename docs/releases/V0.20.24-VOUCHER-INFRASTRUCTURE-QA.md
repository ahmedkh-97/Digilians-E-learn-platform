# V0.20.24 — Voucher Infrastructure QA

Date: 2026-09-02

## Scope

This release adds the Voucher subsystem infrastructure only. It does **not** ship production Voucher questions yet.

Included foundations:

- Voucher as a first-class Home and Navbar destination.
- Five fixed tracks: Data Analysis, Marketing, Graphic Design, UI/UX, Media Production.
- Coming Soon behavior for empty tracks.
- Independent Voucher registries, local attempt history, seen-question coverage, and compact Resume metadata.
- Full Source Mock and Random Mock infrastructure.
- Safe option shuffle tied to stable option IDs.
- Locked option order for wording that depends on A/B/C/D, All of the above, None of the above, etc.
- Unseen-First selection with blueprint/topic balancing support.
- Timed/Untimed and Exam Mode/Instant Feedback foundations.
- Primary Track selection for learner identity and Voucher Track Overall eligibility.
- Voucher source/track/exam filters inside the existing My Mistakes page.
- Wrong-only mistake creation preserved; No Answer remains excluded.
- Voucher Exam Ranking and Track Overall ranking foundations using Real Exam Size attempts only.
- Backup/Restore coverage for Primary Track, Voucher attempt history, and seen-question coverage.
- Optional Supabase `voucher_profiles` migration for shared Primary Track filtering online.
