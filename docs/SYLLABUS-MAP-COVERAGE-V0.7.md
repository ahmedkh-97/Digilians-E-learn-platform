# V0.7 — Syllabus Map + Coverage Blueprint

## Purpose
Large tracks such as Excel, SQL, Python and Power BI can contain many weeks, topics and subtopics.
The Final Exam must not select questions blindly from a large pool.

V0.7 adds:

1. **Syllabus Map**
   - Track
   - Major topics
   - Subtopics
   - Importance: core / important / supporting

2. **Coverage Blueprint**
   - Minimum, target and maximum number of questions per major topic
   - Separate blueprints for Track Exams and Final Exam shares

3. **Coverage Engine**
   - Selects questions while respecting topic targets
   - Limits over-concentration in one subtopic
   - Avoids adjacent repeated topics when possible

4. **Topic Analytics**
   - Exam result includes topic-level performance

## Final selection order
Track quota → Topic coverage → Difficulty/source constraints → Question type mix → Anti-repeat rules.

## Important
Coverage blueprints are versioned and must be recalculated whenever a track curriculum changes materially.
