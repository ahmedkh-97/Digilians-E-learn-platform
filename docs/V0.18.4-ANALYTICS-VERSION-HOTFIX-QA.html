V0.18.4 — Analytics Version Tracking Hotfix QA

Reported defect

Private Analytics → Recent Activity displayed:

Vunknown

for every event.

Root cause

V0.18.3 stored data-build-version on #environmentBanner.

Analytics read only:

document.documentElement.dataset.buildVersion

The HTML root had no build-version dataset, so currentVersion() returned unknown.

The same mismatch also existed in the Live Update installed-version reader, although its fallback release masked the issue in normal use.

Fix

New shared module:

assets/js/build-version.js

Exports:

  • normalizeBuildVersion
  • resolveBuildVersion
  • displayBuildVersion

Analytics and Live Update import the same versioned module.

The <html> root now also contains:

data-build-version="0.18.4"

Resolver rules

  1. HTML root
  2. generic [data-build-version]
  3. environment banner
  4. explicit fallback

Only valid semantic major.minor.patch values are accepted.

Analytics display

Valid:

  • 0.18.4 → V0.18.4

Invalid / missing:

  • unknown → Unknown

Vunknown is no longer produced.

Historical data

Analytics started in V0.18.3.

Included SQL:

supabase/BACKFILL-ANALYTICS-VERSION-V0.18.4.sql

It updates only:

platform_version = 'unknown'

to:

0.18.3

No educational or ranking data is touched.
