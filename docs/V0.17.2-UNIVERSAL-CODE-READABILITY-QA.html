V0.17.2 — Universal Code Readability System

Goal

Code-like questions must not be presented as oversized paragraph text.

The platform now uses one technical-content presentation layer for Python, SQL, DAX, Excel formulas and Power Query M.

Architecture

New module:

assets/js/technical-content.js

Responsibilities:

  • infer language from question metadata and code signatures;
  • separate prose from multi-line code without editing source JSON;
  • distinguish inline technical expressions from code blocks;
  • render code-safe HTML;
  • syntax-highlight locally with no third-party dependency;
  • preserve code indentation;
  • add line numbers only to multi-line blocks;
  • format code answer options;
  • format inline technical expressions in feedback.

Learner surfaces

The renderer is wired into:

  1. Official QBank Study question
  2. Official QBank answer options
  3. Official QBank answer/explanation
  4. Practice / Exam question
  5. Practice / Exam answer options
  6. Instant Feedback
  7. Result Review
  8. Python Study Quick Checks
