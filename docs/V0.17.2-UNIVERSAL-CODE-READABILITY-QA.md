# V0.17.2 — Universal Code Readability System

## Goal

Code-like questions must not be presented as oversized paragraph text.

The platform now uses one technical-content presentation layer for Python, SQL, DAX, Excel formulas and Power Query M.

## Architecture

New module:

`assets/js/technical-content.js`

Responsibilities:
- infer language from question metadata and code signatures;
- separate prose from multi-line code without editing source JSON;
- distinguish inline technical expressions from code blocks;
- render code-safe HTML;
- syntax-highlight locally with no third-party dependency;
- preserve code indentation;
- add line numbers only to multi-line blocks;
- format code answer options;
- format inline technical expressions in feedback.

## Learner surfaces

The renderer is wired into:
1. Official QBank Study question
2. Official QBank answer options
3. Official QBank answer/explanation
4. Practice / Exam question
5. Practice / Exam answer options
6. Instant Feedback
7. Result Review
8. Python Study Quick Checks

## Visual component QA

A headless Chromium component render was performed using the real production CSS and real official question payloads.

### Python NumPy
Official Python Q0016:
- code block rendered at normal code scale rather than heading scale;
- 4 source lines rendered as 4 visual code lines;
- no phantom blank lines;
- question prompt rendered below the code block;
- options remained readable.

A phantom-line issue was discovered during this visual check because inherited `white-space: pre-wrap` was creating visual whitespace around block children. It was fixed before packaging by:
- removing newline text nodes between rendered code-line spans;
- explicitly neutralizing inherited white-space on technical containers.

### SQL
Official SQL Q0001:
- four multi-line query options rendered correctly;
- query blocks fit inside option cards;
- no horizontal page overflow at desktop size.

### DAX / Power Query M
Dark-theme component rendering was checked:

### Mobile
A 390px component viewport was checked:
