# V0.17.0 — Visual Learning & Study UX Fixes

## 1. RTL/LTR and entity defect

The previously observed `;amp&` display was not present in the curriculum JSON. It was created at render time:

1. `escapeHtml()` converted `&` to `&amp;`.
2. The old mixed-language regex then interpreted the letters `amp` as English technical text.
3. Arabic RTL layout could visually expose/reorder the entity fragment.

### Fix

Presentation formatting is now isolated in:

`assets/js/study-format.js`

The formatter:
- normalizes known entities first;
- escapes output safely afterward;
- keeps pure English/code expressions inside a single LTR `<bdi>`;
- isolates technical chunks inside Arabic prose.

Regression cases include:
- `List & Converters`
- `List &amp; Converters`
- `Function = Input → Process → Output`
- Arabic sentence containing `List & Converters` and `map()`.

## 2. Python Visual Learning
