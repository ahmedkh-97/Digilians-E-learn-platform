V0.19.1 — Profile Access & Layering Fix QA

Reported issues

  1. Sticky Navbar remained visually above the Profile backdrop.
  2. Exam / Bank JSON Validator was visible to Guest users.
  3. Profile actions were becoming cluttered after Backup/Analytics additions.

Layer contract

  • Navbar = 120
  • Update notice = 150000
  • Profile backdrop = 155000
  • Profile drawer = 155100
  • What’s New = 160000
  • Admin Login = 170000
  • Backup / Restore = 175000
  • LOCAL TEST banner = 180000

Therefore, Profile covers normal navigation/update UI, while higher-level modals can still open above it.

Interaction lock

While Profile is open:

  • body overflow = hidden
  • .app-shell has inert
  • Profile close receives focus
  • backdrop click closes
  • Escape closes
  • close button closes
  • prior focus is restored

Buttons that open another modal/private route close Profile first.

Admin Tools

Guest/default:

  • adminProfileTools = hidden
  • Analytics = hidden
  • JSON Validator = hidden

Verified Supabase Admin:

  • adminProfileTools becomes visible
  • Analytics becomes visible
  • JSON Validator becomes visible
  • window.__DIGILIANS_ADMIN_VERIFIED__ = true

Logout/session failure:

  • Admin Tools are hidden
  • verification flag returns false

Validator also has a hard app-side guard.
