## Privacy

Storage key:
`digilians.avatarProfile`

Contains:
- schema version
- category
- avatar ID
- local update timestamp

The Avatar module:
- has no `fetch()`
- emits no Analytics event
- sends no category/gender value to Supabase
- sends no avatar choice to ranking
- uses local SVG only

Backup/Restore includes the avatar profile because the learner explicitly owns/downloads that backup.
