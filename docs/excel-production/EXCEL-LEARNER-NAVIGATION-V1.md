# Excel Learner Navigation V1

## Learner-facing hierarchy

### Level 1 — Excel Track

Shows:
- Module count
- total mapped topics
- assessment status
- 8 `What You'll Learn` relationship groups

### Level 2 — Module

`Excel Foundations & Data Handling`

The module is no longer a direct Study shortcut.

Clicking it opens the Content Map.

### Level 3 — Content Map

8 Learning Groups:

1. Visual Formatting & Rule Logic
2. Formula Language & Core Calculations
3. Text Cleaning & Transformation
4. Logic, Lookup & Dynamic References
5. Dates & Working-Day Calculations
6. Statistics for Excel
7. Dynamic Arrays & Conditional Calculations
8. Data Handling & Analysis Tools

### Level 4 — Group Overview

The learner sees:
- what the Group solves
- why the lessons belong together
- lesson flow
- progress
- exact lesson list

### Level 5 — Lesson

Only after choosing a lesson does Study open.

Study is Group-scoped so the learner is not dropped back into a 27-topic wall.
