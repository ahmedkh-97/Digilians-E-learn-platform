# Excel Production Contract — 3 Weeks

## Locked rules

1. Uploaded files are the educational source of truth.
2. No outside Excel topics are silently added.
3. Sequence is content-based, not filename-based.
4. Every published Study topic has source trace.
5. Every assessment question has source/concept trace.
6. No week is marked ready before coverage audit.
7. No Excel Track Final is enabled before **all 3 weeks** are audited.
8. Lecture count per week is source-dependent and must not be invented.
9. Current SQL, Python, Official QBank, ranking, Analytics, Backup, Avatar, and platform-core behavior must not regress during Excel production.

## Excel Study quality target

After every section, the learner should be able to answer:
- What does this Excel concept/feature do?
- How do I use or evaluate it correctly?
- What mistake or exam trap is most likely here?

## Formula readability

Excel formulas use the existing Universal Technical Content system. Formula blocks remain LTR, compact, copy-readable, and visually separate from Arabic explanations.

## Tables / screenshots / workbook visuals

When meaning depends on cell layout, ranges, table structure, chart shape, ribbon/menu placement, or before/after workbook state, Study should provide an appropriate visual representation instead of relying on prose alone.

Source screenshots can be represented faithfully when available. Platform-created visuals must be labeled as clarifications if they are not direct source images.
