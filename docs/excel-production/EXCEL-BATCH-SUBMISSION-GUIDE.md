# Excel Files — Batch Submission Guide

## What to send

Send the course **week by week** whenever possible:

- Week 1: all available Week 1 lecture files
- Week 2: all available Week 2 lecture files
- Week 3: all available Week 3 lecture files

There is **no assumed lecture count per week**.

If one week contains unusually large decks, it can be split into Part A / Part B while preserving the same week number.

## Do not rename files just for the platform

Original filenames are useful for source traceability. Professional display names are assigned only after reading the actual content.

## What happens after each week is uploaded

1. Inventory every file.
2. Read content and infer the real sequence.
3. Detect duplicates / overlap / continuation lectures.
4. Surface only real scope ambiguities that need a user decision.
5. Build the week's curriculum registry.
6. Build Study sections.
7. Build assessment banks.
8. Run source / coverage / render QA.
9. Mark the week ready.

## Excel-specific preservation rules

- Preserve formula/function spelling from source.
- Preserve examples and workbook logic from source.
- Preserve range/reference style exactly when assessment meaning depends on it.
- Do not silently convert comma/semicolon formula separators unless the source does so.
- Treat Power Query M, Power Pivot/DAX, PivotTables, charts, data cleaning, formulas, functions, and workbook features according to how the course presents them.
- If the source has a typo that would break a formula/example, preserve source trace and label any display correction explicitly.

## What is needed from the user

Normally: only the files and their week number.

A question is asked only when there is a genuine scope choice, contradiction, exclusion, or instructor-specific rule that the material cannot resolve.
