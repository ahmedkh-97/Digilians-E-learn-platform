Excel Deep Learning Standard V3.2

Goal

A learner with zero prior Excel knowledge should be able to open a lesson, read it in order, and understand:

  1. what the concept means
  2. why it exists
  3. how it connects to nearby Excel concepts
  4. the important terms
  5. a simple example
  6. the visual / cells / workflow when layout matters
  7. the source-supported formula or steps when present
  8. the common mistakes
  9. a small practice task
  10. a Quick Check
  11. what comes next

The learner-facing explanation must teach directly.

Do not write learner explanations such as:

  • “المصدر بيشرح…”
  • “المصدر بيقول…”
  • “حسب المصدر…”

Source identity belongs in Source Trace at the end of the lesson, or in explicit Source Gap / Presentation Correction warnings.

Required Deep Lesson components

Every lesson now includes:

  • Learning Goal
  • How This Connects
  • Understand From Zero
  • Concepts Made Simple
  • Simple Example
  • Why Do I Need This?
  • Visual Model when supported
  • Formula Lab when formulas are explicitly present
  • Workflow when procedural steps are explicitly present
  • Common Mistakes
  • Try It Yourself
  • Quick Check
  • Next Connection
  • Source Trace

Richer lessons may additionally include:

  • See It in Excel
  • Worked Examples
  • Formula Anatomy
  • Execution Trace
  • Expected Result
  • Comparison Table
  • Decision Table

Platform Clarifications

Platform-created teaching devices are allowed only when they explain a source-supported concept.

Examples:

  • small teaching dataset
  • simplified calculation trace
  • relationship map
  • comparison layout
  • Try It exercise
  • Quick Check

They must be labeled as a Platform Clarification where appropriate.

Formula integrity

  • formula text remains LTR
  • formulas use the Universal Technical Renderer
  • no unsupported formula syntax is invented
  • if a function appears only in a source assessment and is not taught, log a Source Gap rather than inventing a lesson

Statistics Decision B

Statistics content remains:

PREREQUISITE • STATISTICS

It is allowed to contain Study Quick Checks for learning.

It remains excluded from:

  • Excel Practice scoring
  • Excel Week Exam
  • Excel Track Final
  • Excel share of the Data Analysis Final

Readability baseline

Excel Study V3.1 typography is retained.

Desktop core reading targets:

  • Arabic main explanation: ~16px
  • concept explanations: ~14px
  • common-mistake / practice text: ~13.5px or larger
  • technical formulas: independently readable LTR

Mobile:

  • no page-level horizontal overflow
  • grids collapse to one column when needed
  • formula/table containers may scroll internally if required

Assessment gate

Practice and Exam remain locked until the full Study rollout is reviewed and accepted.
