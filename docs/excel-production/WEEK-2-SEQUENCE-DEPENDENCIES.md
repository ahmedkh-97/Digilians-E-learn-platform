# Excel Week 2 — Content-Based Sequence & Dependencies

## Recommended source sequence

1. **Advanced Data Management, Search Automation & Consolidation** — Bridge from Week 1; reuse existing Sparklines/Consolidation/Form/Search and add ActiveX/VBA/3D-reference behavior.
2. **Chart Selection & Visual Analysis** — Establish chart purpose and recognition before table/dashboard design.
3. **Table Visualization & Readability** — Teach information density, spacing, alignment and highlighting before dashboard composition.
4. **Outlier Detection & What-If Analysis** — Reuses Week 1 statistics as Excel application: QUARTILE.INC, Box & Whisker, STANDARDIZE and Goal Seek.
5. **Optimization & Excel Automation** — Goal Seek naturally precedes Solver; Python-in-Excel remains a cross-track automation bridge.
6. **Dashboard Design Principles & Evaluation** — Define focus, audience, hierarchy and KPI actionability before constructing dashboards.
7. **Interactive Dashboards & Storytelling** — Build on charts + table design + dashboard principles using PivotTables, slicers, timelines and storytelling.
8. **Power Query Foundations & M** — Introduce ETL, Applied Steps and M syntax before advanced combine/load operations.
9. **Power Query Transform, Combine & Data Model** — Deepen Lecture 26 into transformation, merge/append, refresh and Data Model analysis.
10. **External Data Sources & Managed Connections** — Cap the flow with SQL Server/Access/SQLite/multi-source connection and refresh workflows.

## Learner-facing continuation after Week 1

- **Group 09 — Advanced Data Management & Search Automation**: Week 1 filtering/consolidation tools → ActiveX/VBA search automation → multi-sheet consolidation techniques.
- **Group 10 — Chart Selection & Visual Analysis**: Question you want to answer → choose chart family → format/elements → interpret trend, comparison, relationship or distribution.
- **Group 11 — Table Design & Readability**: Data ink → grids/white space → color/highlighting → alignment → readable analytical table.
- **Group 12 — Outliers, Goal Seek & Optimization**: Detect unusual values → test a target with Goal Seek → optimize multiple variables/constraints with Solver.
- **Group 13 — Dashboard Design, Interactivity & Storytelling**: Audience/focus → visual hierarchy → Pivot summaries/charts → slicers/timelines → story → action.
- **Group 14 — Excel Automation Bridge**: Solver automation → Python in Excel → Pandas bridge. Keep Python fundamentals in the existing Python track.
- **Group 15 — Power Query Foundations & M**: Connect → Transform → Combine → Load; UI actions become Applied Steps and M code.
- **Group 16 — Power Query Integration & External Data**: Transform/merge/append → Data Model/load → external database/file connections → refreshable analysis.

## Dependency rules

- Week 1 FILTER/Search → Week 2 ActiveX/VBA search
- Week 1 IQR/SD prerequisites → Week 2 QUARTILE.INC / STANDARDIZE
- Goal Seek → Solver
- Chart foundations → table design → dashboard design → dashboard build
- Power Query ETL → M/Applied Steps → Merge/Append → Data Model → external connections
- Python-in-Excel → link to the existing Python track; never duplicate Python/Pandas fundamentals
