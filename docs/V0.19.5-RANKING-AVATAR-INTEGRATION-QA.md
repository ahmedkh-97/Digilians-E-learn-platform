# V0.19.5 — Ranking Avatar Integration QA

## Reported issue

The selected Soft 3D avatar appeared correctly in Navbar/Profile, but Ranking still rendered learner initials.

Example:

`Ahmed Khaled` showed `AK` in the highlighted `YOU` row even though the Navbar showed a Soft 3D avatar.

## Root cause

Ranking renderers predated the Avatar Profile feature and generated initials directly from `student_name`.

Affected surfaces:
- normal exam leaderboard
- aggregate / Official Total Grades leaderboard
- podium

## Fix

New display helper:

`rankingAvatarHtml(entry, isMe)`

Behavior:
- if `entry.player_id === state.playerId` and a valid local avatar exists → render local Soft 3D image
- otherwise → render initials

Applied to:
1. exam ranking rows
2. aggregate ranking rows
3. podium positions

## Privacy model

No backend schema change.

Avatar data is still not uploaded with ranked attempts.

Therefore:
- this browser can display its own avatar from local profile state
- it cannot display other learners' private local avatar choices
- other learners remain initials

This keeps the established V0.19.4 avatar privacy contract intact.
