V0.18.1 — Technical Feedback CSS Hotfix QA

Reported defect

In Instant Feedback, a correct SQL answer appeared extremely tall and fragmented.

The SQL source itself was correct and contained four lines.

The defect was CSS inheritance.

Root cause

The selector:

.technical-feedback-answer span

was intended for the YOUR ANSWER / CORRECT ANSWER labels.

Because the technical renderer uses <span> elements for syntax highlighting, the selector also applied:

display: block

to tokens inside the SQL code block.

That split code tokens vertically.

A second historical risk was found:

.official-option span:last-child

This descendant selector could reach nested technical markup rather than only the answer text wrapper.

Fix

The feedback label selector is now:

.technical-feedback-answer > div > span

The Official QBank answer wrapper is now targeted as:

.official-option > .option-content

Defensive technical CSS also ensures:

  • code-line containers remain flex
  • code source remains preformatted
  • syntax tokens do not inherit answer-label margins

Exact data regression

Question:

official-sql-q0001

Correct answer:

SELECT CustomerID, SUM(Amount)
FROM Orders
GROUP BY CustomerID
HAVING SUM(Amount) > 50000;

The shipped Pre-Deploy check verifies:

  • language = SQL
  • exactly four rendered technical code lines
  • unsafe descendant selectors are absent
  • scoped replacement selectors exist

Chromium component regression

The exact reported answer was rendered twice inside the real Instant Feedback markup:

  • YOUR ANSWER
  • CORRECT ANSWER

Using the production stylesheet.

Computed-style assertions:

  • rendered code lines: 8 total = 4 + 4
  • SQL keyword token display: inline
  • .technical-code-source display: block
  • .technical-code-source white-space: pre
  • first code block height: ~144 px
  • page-level horizontal overflow: 0

Result: PASS.
