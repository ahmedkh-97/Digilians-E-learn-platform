# V0.17.1 — Study Polish & Reliability QA

## Scope

V0.17.1 deliberately avoids adding another large product feature. It focuses on the defects visible after V0.17.0 and on preventing a blank-screen failure from reaching learners.

## 1. Arabic prefix + English technical term

Observed issue:

`Expected Outputال`

The renderer now detects Arabic article prefixes directly attached to English technical terms and wraps the combined visual unit safely.

Regression examples:
- `اكتب الـExpected Output على ورقة`
- `راجع الـfor loop قبل الحل`
- `Function = Input → Process → Output`
- `List & Converters`

The renderer continues to normalize encoded entities before safe HTML escaping.

## 2. Quick Check persistence

Quick Check state is now stored under:

`digilians.quickChecks`

Scope:

`student name → module → section`

Stored fields:
- selected answer
- correct/incorrect
- answered timestamp

A saved answer is restored when the learner refreshes or returns to the Study topic.

`Reset Quick Check` removes only the current student's current section checkpoint.

It does not change:
- Study completion
- Practice scores
- Exam results
- Ranking
- other users
- other sections

## 3. Quick Check feedback

Feedback now explicitly separates:
- YOUR ANSWER
- CORRECT ANSWER
- Arabic explanation

For the checkpoint:

`for ch in "Python"`

the explanation also traces:

`P → y → t → h → o → n`

This makes the answer concept-specific rather than only repeating a general loop definition.

## 4. Readability

Arabic helper labels and Study source micro-copy were enlarged.

## 5. Startup / crash recovery

A Recovery Screen exists directly in `index.html`, independent of the main `app.js` module.

It can appear when:
- a JavaScript startup error occurs;
- a required script/module fails to load;
- an unhandled startup promise rejects;
- the app fails to signal readiness within the watchdog window;
- platform data cannot be loaded.

Actions:
- Reload Platform
- Clear App Cache & Reload

The recovery actions do not clear `localStorage`, so saved Study progress and completed results are preserved.
