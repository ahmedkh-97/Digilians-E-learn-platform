V0.18.8 — Proportional Navbar Scale QA

Reported issue

The navbar was widened in V0.18.7, but the labels, branding and profile controls still looked too small inside the enlarged header.

The result was visually unbalanced: a large surface with undersized internal content.

Fix

Large desktop screens now use a proportional scale:

  • topbar height: ~80px rendered
  • center nav width: 650px
  • each of 5 tabs: ~124px
  • nav font: 10.3px
  • brand title: 13px
  • subtitle: 7.4px
  • logo: 44px
  • profile name: 9.2px
  • theme button: 42px

Tablet and mobile retain smaller responsive values instead of inheriting the large-screen scale.
