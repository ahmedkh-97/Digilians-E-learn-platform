V0.18.5 — Sticky Navigation & Course Card Layout Fix

Reported issues

  1. The desktop primary navigation was only at the top of the page and disappeared while scrolling.
  2. Long course descriptions could visually collide with the absolute-positioned course footer/count/arrow.

Fix 1 — Sticky primary navigation

.topbar now uses:

  • position: sticky
  • top: 0
  • higher z-index
  • light translucent background
  • backdrop blur
  • subtle bottom border/shadow

The navigation remains available while the learner scrolls.

Local TEST mode has an offset so the sticky navigation does not cover the purple TEST banner.

Fix 2 — Course card layout

Course cards now use a flex-column normal-flow layout.

The footer is no longer absolutely positioned.

New structure behavior:

  • icon / title / description stay in normal document flow
  • footer uses margin-top: auto
  • footer has protected top padding
  • long descriptions can increase card height naturally
  • count and arrow cannot sit on top of description text

Chromium component QA

Production CSS + actual course titles/descriptions from data/learning.json were rendered.

Desktop:

  • topbar computed position = sticky
  • after 900px scroll, topbar top = 0
  • minimum visible paragraph → footer gap:
    • English: 39.5px
    • Soft Skills: 39.5px
    • Leadership: 39.5px
    • Data Analysis: 22.4px
  • horizontal page overflow = 0

390px mobile:

  • sticky top = 0
  • minimum visible paragraph → footer gap = 22.4px
  • horizontal page overflow = 0

Result: PASS.
