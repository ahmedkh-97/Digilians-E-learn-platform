V0.18.6 — Modern Minimal UI Polish QA

Goal

Reduce visual sharpness and UI density without redesigning the product or changing behavior.

The target areas were:

  • sticky desktop header
  • Official QBank track hero
  • Official QBank metric summary
  • Official section cards
  • action hierarchy

Header

Sticky navigation is preserved.

Visual changes:

  • top: 10px desktop floating offset
  • 18px rounded glass container
  • lighter border and shadow
  • smaller navigation pills
  • softer active state
  • compact profile/theme controls

TEST-LOCAL retains a separate offset so its environment banner does not collide with the header.

Official Track hierarchy

Actions now render as:

  1. Study All Questions — Primary
  2. Random Practice 40 — Secondary
  3. Random Exam 50 — Secondary
  4. Track Ranking — Ghost

This prevents four equally heavy actions competing for attention.

Summary metrics

Reviewed / Best Sections / Overall Rank now use:

  • softer background
  • lighter border
  • less height
  • smaller typography

Section cards

Changes:

  • lighter border and shadow
  • subtle hover lift
  • smaller number badge
  • score strip uses borderless soft cells
  • reduced nested-card appearance

Actions:

  • Study — Secondary
  • Solve & Rank — Primary
  • Ranking — Ghost
