# Local Release Workflow

`Approved Local Baseline → Change → Targeted TDD → QUICK-CHECK → FULL-QA → ZIP → Manual Local Acceptance`

GitHub is not part of this workflow unless explicitly requested by the project owner.

## Windows shortcuts
- `QUICK-CHECK.bat`: fast validation only.
- `START-LOCAL.bat`: quick validation, then localhost.
- `FULL-QA.bat`: full automated validation only.
- `TEST-LOCAL.bat`: full automated validation, then localhost for manual acceptance.
